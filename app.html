⬇ App Download करें (Android)

Install कैसे करें / How to install

  1. ऊपर का button दबाएं, APK download होगा।
    Tap the button, the APK downloads.
  2. Download पूरा होने पर file खोलें।
    Open the downloaded file.
  3. “Unknown apps / अज्ञात ऐप” की permission Allow करें, फिर Install दबाएं।
    Allow install from this source, then tap Install.
  4. App खोलें → Google से Sign in करें → अपनी profile भरें।
    Open the app, sign in with Google, fill your profile.

📱 App खोलें (iPhone)

iPhone पर App कैसे लगाएं / Add to Home Screen

  1. ऊपर का button Safari में दबाएं, App खुलेगा।
    Tap the button in Safari — the app opens.
  2. नीचे Share (⬆️ वाला icon) दबाएं।
    Tap the Share icon at the bottom.
  3. “Add to Home Screen / होम स्क्रीन में जोड़ें” चुनें → Add।
    Choose Add to Home Screen, then Add.
  4. Home screen से App खोलें → Google से Sign in → profile भरें।
    Open it from your home screen, sign in with Google, fill your profile.
